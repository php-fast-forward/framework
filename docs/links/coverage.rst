Coverage and Reports
====================

The framework repository publishes the following external reports:

- `Coverage Report <https://php-fast-forward.github.io/framework/coverage/index.html>`_
- `Testdox Report <https://php-fast-forward.github.io/framework/coverage/testdox.html>`_

These reports are useful when you want to understand which parts of the package are currently
covered by automated tests before changing the service provider or expanding the framework surface.
