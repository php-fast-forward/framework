FAQ
===

Frequently Asked Questions
-------------------------

**Q: What is the Fast Forward Framework?**
A: It is a lightweight, modern PHP framework that aggregates all core components of the Fast Forward ecosystem for easy installation and management.

**Q: What PHP version is required?**
A: PHP 8.3 or higher.

**Q: How do I install it?**
A: Run ``composer require fast-forward/framework``.

**Q: Can I use my own service providers?**
A: Yes, you can add or override service providers as needed.
